ETOPO2022 Analyzer @VERSION@（Windows x64 离线验收候选版）

使用方法
1. 将 ZIP 完整解压到本地文件夹，不能在压缩包里直接运行。
2. 双击 Check.cmd，确认 passed 为 true。
3. 双击 StartDemo.cmd 检查合成示例数据；Start.cmd 启动正式系统。
4. 如需安装到当前用户目录，双击 Install.cmd，安装成功后创建桌面快捷方式。
   无需安装独立 Python、QGIS 或管理员权限。勿拆散 runtime、src 等目录。
   Start.cmd 和 StartDemo.cmd 通过 Launcher.exe 启动，须保留该文件；不会常驻空白终端窗口。

适用环境
Windows 10/11，64 位；建议至少 8 GB 内存。解压和安装请预留 8 GB 空间。
本版锁定随包 QGIS/Python 环境，不使用系统里的其他 Python。
未作数字签名；如电脑的组织策略禁止脚本，需联系设备管理员使用允许的部署方式。

数据与文件
data/demo.tif 为程序生成的合成地形，仅供功能验收，不代表真实地理观测。
完整 ETOPO 全球 DEM 单独存放，通过“文件→打开栅格”选择；请勿放到 Windows 系统目录。
默认成果位置：%LOCALAPPDATA%\ETOPO2022Analyzer\outputs
启动日志和自检报告：%LOCALAPPDATA%\ETOPO2022Analyzer\logs
保存工作状态保存的是数据路径引用，不会复制数据。换电脑后应重新载入对应数据并保存工作状态。
退出或打开另一份工作状态时，未保存的图层、参数、多边形及成果会触发“保存 / 不保存 / 取消”提醒。
地图导出可勾选包含当前启用的统计区、A/B 多边形，保留边界、填充、名称、图例和范围元数据。

升级与移除
每个版本安装到独立目录。同版本再次运行原始解压包中的 Install.cmd 会修复安装，安装中断或自检失败后可以重试。
修复前关闭程序，并保留原始解压包。Install.ps1 支持 -Destination 指定目标目录；不会接管无安装记录的已有目录。
卸载：Windows 设置→应用→已安装的应用，找到相应版本，选择卸载；也可运行安装目录中的 Uninstall.cmd。
卸载需确认，仅移除安装清单内的程序文件及本版本快捷方式；保留用户输出、工作状态及自行加入的文件。
旧 rc1 为便携包，无安装记录的旧目录仍采用手动移除，不会被新版自动删除。新版当前版本见 release.json 和程序“关于”。
本说明是运行包快速说明，不替代最终提交的统一封面使用说明书和安装配置手册。

验收要求
已做本机独立路径自检不等于已做其他电脑验收。请在无开发环境的目标电脑上运行 Check.cmd，
并人工检查打开数据、地图浏览、裁剪、地形分析、剖面、统计、多边形 A/B 对比和导出。
保留该电脑的自检 JSON 和人工验收记录后，才能判定跨设备交付通过。
